# Adjoin

Position shapes side by side (horizontally or vertically) and center them along the anchor element. Adds more flexibility to the native alignment commands.

## Usage

1. Select all elements that should be moved (they will be ordered left-to-right for **Horizontally**, or top-to-bottom for **Vertically**)
1. Select the reference/anchor element (the one that should not move) **last**
1. Go to **Extensions > Slides Power Toys > Adjoin** and select **Horizontally** or **Vertically**
