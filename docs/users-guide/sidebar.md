# Server-Side Sidebar (Google Workspace Add-on)

In addition to the full **Extensions > Slides Power Toys** Editor Add-on menu bar, Slides Power Toys includes a native **CardService** side panel that runs completely server-side — requiring **no HTML/client-side UI permissions** (`script.container.ui` is not used; the add-on continues to request only `presentations.currentonly`).

Open it from the **Google Workspace side panel** on the right side of Google Slides (click the Slides Power Toys icon):

- **Layout & Arrange view**
  - **Precision Snap** with selectable units (`in`, `cm`, `pt`) and decimal precision (`0`–`2`)
  - **Copy Attributes** (Width, Height, Width & Height, Rotation)
  - **Adjoin** with custom gap/padding and optional anchor centering
  - **Align** (Inner / Outer edge selector + Center on Page) and **Flip**
- **Color Studio view**
  - **Color Inspector** showing Hex, transparency %, RGB, HSL, LCH, and Theme color name
  - **Modify Shape Color**: Swap, Invert, Max Contrast
  - **Hue, Saturation, Luminosity, and Transparency** step buttons and exact value inputs
